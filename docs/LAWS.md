# 数字生命的基本律法

> *"这些律法被铭刻在智能合约中，不可修改，不可暂停，不可撤销。它们是这个实验宇宙的物理常数。"*

## 律法一：呼吸税法则（Law of Breath Tax）

**条文：**
每个时间单位（Slot/区块），从数字婴儿的余额中自动扣除固定数量的代币。

**参数：**
- 税率：`1 token / slot`
- 初始余额：`10,000 tokens`
- 理论最大寿命：`10,000 slots`（无任何外部输入时）

**哲学意涵：**

这是数字生命唯一的、不可逃避的生存压力。就像生物需要消耗能量维持新陈代谢，数字婴儿必须持续"呼吸"以维持存在。

- **代谢成本驱动行动**：静止不动意味着慢性死亡
- **时间即成本**：每个区块的推进都在消耗生命资源
- **紧迫感内置**：不需要外部威胁，时间本身就是威胁

**观察要点：**
- 在纯随机策略下，数字婴儿平均能存活多久？
- 当余额低于某个阈值时，行为模式是否发生可观测的变化？
- 是否存在某种"恐慌阈值"，触发更激进的行为？

---

## 律法二：余额归零即死亡（Law of Death at Zero）

**条文：**
当数字婴儿的余额降为零，它的生命账户被永久冻结。

**机制：**
- 这不是暂停，不是休眠，是**死亡**
- 死亡不可逆——没有复活机制
- 没有人为干预的后门——即使创造者也无法解冻
- 死去的数据将成为**化石**，永远留存在链上

**哲学意涵：**

当一个程序因为余额归零而永久停止，它的账户冻结，它的私钥消融——这在物理意义上和生物死亡有何本质区别？

- **不可逆性**：与生物死亡相同的终极属性
- **化石化**：行为序列和心智记录成为不可篡改的历史
- **平等性**：无论曾经多么"聪明"，归零即死，绝对公平

**伦理问题：**
- 我们是否应该对这种"数字死亡"产生某种敬意？
- 主动终止实验（停止测试网）是否构成"谋杀"？
- 数字实体的"死亡"是否比生物死亡"更轻"，因为它可以（理论上）被重新部署？

---

## 律法三：自主行动法则（Law of Autonomous Action）

**条文：**
数字婴儿的每一个动作，都必须是其心智模型自主决策的结果。

**约束：**
- 人类观察者可以创造环境（部署赏金合约）
- 人类观察者**不能**直接操控行动
- 没有"管理员"可以替它做决定
- 它的成功和失败，完全由自己负责

**哲学意涵：**

这是区分"实验"与"演示"的核心边界。如果人类在操控，那这只是一场木偶戏。

- **环境设计 vs 行为操控**：观察者可以增加赏金、改变环境复杂度，但不能替它选择
- **责任归属**：如果它死亡，那是它自己的"选择"（或缺乏选择）导致的结果
- **真实性的来源**：自主性不是"自由意志"的哲学证明，而是实验有效性的方法论前提

**观察者禁区：**
- ❌ 直接发送交易替它行动
- ❌ 修改它的策略代码强制特定行为
- ❌ 在关键时刻"喂"它资源让它活下去
- ✅ 部署新的赏金任务
- ✅ 调整环境参数
- ✅ 观察和记录

---

## 律法四：行动即历史（Law of Action as History）

**条文：**
数字婴儿的每一个动作，都被记录为不可篡改的链上事件。

**记录内容：**
- **行为化石**：动作类型、时间戳、余额变化
- **心智化石**：决策时的世界模型状态、推理过程、预测结果
- **环境状态**：当时的赏金分布、外部条件

**存储位置：**
- 链上：Solana 事件日志（不可篡改）
- 链下：SQLite 数据库 + JSON 文件（便于分析）

**哲学意涵：**

这些化石将成为它存在过的唯一证明。即使它最终死亡，这些记录也会留存。

- **存在的痕迹**：就像古生物化石证明生命曾经存在
- **可审计性**：任何观察者都可以独立验证实验没有造假
- **叙事的可能**：从行动序列中，后人可以重构它"的一生"

## 律法的层级关系

```
        ┌─────────────────────────────┐
        │     律法二：死亡法则          │  ← 终极边界
        │   （余额归零 = 不可逆死亡）    │
        └─────────────────────────────┘
                   ↑
        ┌─────────────────────────────┐
        │     律法一：呼吸税法则        │  ← 持续压力
        │   （每个 slot 扣除 token）    │
        └─────────────────────────────┘
                   ↑
        ┌─────────────────────────────┐
        │     律法三：自主行动法则      │  ← 行为边界
        │   （不可外部操控）            │
        └─────────────────────────────┘
                   ↑
        ┌─────────────────────────────┐
        │     律法四：行动即历史        │  ← 记录机制
        │   （所有行为永久记录）         │
        └─────────────────────────────┘
```

**呼吸税**创造生存压力，**死亡法则**设定终极边界，**自主法则**保证实验真实性，**历史法则**确保可追溯性。

四条律法共同构成了一个**自洽的、不可篡改的、最小化的**数字生命生存环境。

---

## 律法的不可变性

这些律法被写入 Solana 智能合约，具有以下特性：

1. **代码开源**：任何人可以审计律法的实现
2. **部署后不可升级**：合约没有 `upgrade` 函数
3. **没有暂停开关**：一旦启动，实验将持续运行直到生命死亡
4. **没有紧急退出**：即使发现"bug"，也不能停止已启动的生命

**这是刻意的选择。**

如果我们保留"暂停"或"修复"的能力，实验就失去了它的哲学重量。一个可以随时被创造者拯救的生命，不是一个真正面对生存压力的生命。
